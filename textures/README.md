# Texture Folder Structure

This folder contains textures for 3D floor plan visualization.

## Folder Organization

```
textures/
├── defaults/     ← Put your real textures here (empty by default)
└── fallback/     ← Dummy solid-color textures (auto-generated)
```

## How It Works

When the 3D exporter needs a texture:

1. **First**: Checks `defaults/` folder
   - Use this for custom/realistic textures
   - Generated by AI or manually created
   - Higher priority

2. **Fallback**: If not found in `defaults/`, uses `fallback/`
   - Contains solid-color dummy textures
   - Always available as backup
   - Generated by `generate_dummy_textures.py`

## Usage Examples

### Use All Fallback Textures (Default)
```bash
# defaults/ is empty, all textures come from fallback/
python -m floor_planner -c myconfig.yml
```

### Use Custom Texture for Walls Only
```bash
# Put custom wall texture in defaults/
cp my_brick_wall.jpg textures/defaults/wall.jpg

# Now walls use custom texture, everything else uses fallback
python -m floor_planner -c myconfig.yml
```

### Use All Custom Textures
```bash
# Generate all realistic textures (see docs/TEXTURE_GENERATION.md)
python scripts/generate_textures_dalle.py

# OR manually copy textures to defaults/
cp my_textures/*.jpg textures/defaults/

# Now all elements use custom textures
python -m floor_planner -c myconfig.yml
```

## Regenerating Fallback Textures

If you accidentally delete fallback textures:

```bash
# Regenerate all dummy textures
python generate_dummy_textures.py

# Move to fallback folder
mv textures/defaults/*.jpg textures/fallback/
```

## Texture Requirements

- **Format**: 
  - **PNG (.png)** - Preferred for transparency support (alpha channel)
  - **JPEG (.jpg)** - Standard for opaque textures
- **Size**: 1024x1024 recommended (512x512 minimum)
- **Quality**: 85-95 JPEG quality (or PNG-8/PNG-24 for transparency)
- **Seamless**: Walls/floors should tile seamlessly

### PNG Transparency Support

The system **automatically detects PNG files** and enables alpha channel transparency in 3D models:

- **Use PNG for**: Windows (glass transparency), fences, plants with cutouts, water features
- **Automatic priority**: System checks for `.png` first, then falls back to `.jpg`
- **MTL support**: PNG textures get `map_d` (alpha map) directives automatically

**Example:**
```bash
# Both files exist in defaults/
textures/defaults/window.jpg   # Opaque window texture
textures/defaults/window.png   # Glass with alpha transparency

# System will use window.png automatically (PNG has priority)
python -m floor_planner -c myconfig.yml
```
